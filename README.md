# AgroMind AI
### Intelligent Crop Monitoring and Decision Support System

AgroMind AI is an AI-based crop monitoring project designed to help farmers identify crop leaf diseases and access useful crop health information.

## Key Features
- Plant leaf disease detection
- Disease severity assessment
- Crop health monitoring
- Disease remedies and preventive suggestions
- Smart crop alerts

## Technologies Used
- Python
- Flask
- TensorFlow / Keras
- OpenCV
- MySQL
